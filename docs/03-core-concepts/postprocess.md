# 文本清理（TextPostProcessor）

ASR 输出到注入之间唯一的一层。目标不是"改得更通顺"，而是**去噪**：把不该出现在光标处的内容挡掉。

行为基准：`spike/xifeng/postprocess.py`（Rust 侧 `ime-post` MUST 与之一致，黄金用例见 `spike/tests/test_postprocess.py`）。

## 五步管线（顺序固定）

```
raw
 ├─1 幻觉过滤      整句命中黑名单 → 不注入
 ├─2 连续字折叠    同一字符 >8 连 → 折叠为 2 连
 ├─3 语气词剔除    句首/句中孤立填充词（边界敏感）
 ├─4 归一化        中英补空格、标点去重、空白规整
 └─5 终检          空串 / 全标点 → 不注入
```

顺序不能换：
- 幻觉必须在折叠前（"谢谢观看。。。。" 也要能命中）
- 语气词在归一化前（补空格会让边界判断失效）
- 终检在最后（前面任何一步都可能把文本清空）

## 1. 幻觉过滤

静音/噪声输入下 SenseVoice 会输出训练语料里的客套话（G10）。整句命中即丢弃：

| 模式 | 例子 |
|---|---|
| `^谢谢(大家)?观看[。！!.]?$` | 谢谢观看 / 谢谢大家观看。 |
| `^字幕由.*提供[。！!.]?$` | 字幕由志愿者提供。 |
| `^请不吝(点赞\|转发\|订阅).*$` | 请不吝点赞、订阅。 |
| `^请(点赞\|订阅\|关注)[、，,\s]*.*$` | 请点赞关注 |
| `^[Oo][kK][。！!.]?$` | OK（纯 OK 多为误触） |

约束：
1. 只匹配**整句**，正文里出现这些词不受影响
2. 命中即返回"不注入"，不做部分删除（部分删除会留下半句话）
3. 黑名单 MUST 可配置（M3 GUI），M0 硬编码

## 2. 连续字折叠

```
重复次数 > 8  →  折叠为 2
```

- 保留 2 次是因为"哈哈"是真实表意，折叠成 1 个会改变语气
- 9 连以上几乎全是 ASR 卡死或长音，不是用户想说 9 个"啊"
- 按**字符**而非 UTF-16 码元判断（emoji 重复也适用）

## 3. 语气词剔除

中文里的"嗯/呃/啊/诶/唔/噢/uh/um/emm"等，只在**边界位置**删除。

正则形态（等价）：

```
(^|[，。？！、\s])(?:嗯|呃|啊|…)(?=[，。？！、\s]|$)
```

强制规则：

1. **仅当文本含 CJK 时执行**：英文里 `er` / `um` 是正常词，删了就是改内容
2. **只在边界删除**：`呃逆`（病名）、`啊哈` 这类词中间的不能删
3. **句尾助词默认不删**：`呀/呢/吧/啦/哦` 只在 `filler_level=deep` 时参与，`好啊 → 好` 会改变语气
4. 删除后清理残留的句首标点/空格（`呃，今天` → `，今天` → `今天`）
5. 循环到不动点：`呃，嗯，那个……` 需要多轮才清干净

词表：
- L1 句首、L2 句中（`filler_level=standard`）：`嗯嗯 emm emmm 嗯 呃 啊 诶 哎 唔 噢 uh um`
- L3 句尾（`deep` 才加）：`呀 呢 吧 啦 哦`

整句只有语气词时（如"嗯嗯"）→ 不注入；配置 `standalone=inject` 可改为保留。

## 4. 归一化

| 规则 | 输入 → 输出 |
|---|---|
| 中英之间补空格 | `用PyO3接入` → `用 PyO3 接入` |
| 同类标点去重 | `真的吗？？？` → `真的吗？` |
| 空白规整 | 多空格→单空格；行内首尾空格去掉 |
| 可选去句末标点 | `final_punct=strip`：`今天开会。` → `今天开会` |

注意："，。" **不是**重复标点，不折叠（不同类型相邻是合法的）。

## 5. 终检

空串、纯空白、纯标点、纯表情符号之外的不可见字符 → 不注入。

## 配置项

| 键 | 默认 | 取值 | 说明 |
|---|---|---|---|
| `filler_level` | `standard` | `off` / `standard` / `deep` | `off` 关掉第 3 步 |
| `standalone` | `drop` | `drop` / `inject` | 整句只有语气词时的策略 |
| `repeat_limit` | `8` | ≥1 | 折叠阈值 |
| `final_punct` | `keep` | `keep` / `strip` | 是否去掉句末标点 |
| `space_between_cjk_latin` | `true` | bool | 中英混排补空格 |

## 不变量（改代码前必看）

1. **幂等**：`process(process(x)) == process(x)`
2. **不建新内容**：只删、只调空白与标点，MUST NOT 补词、改词
3. **返回 None 表示不注入**，不是空字符串（空字符串会走进注入逻辑）
4. **不记录文本**：统计只输出 `chars_in / chars_out / dropped`
5. 纯函数：无 IO、无全局可变状态（正则缓存只读）
