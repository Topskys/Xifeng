# review.md — 复审清单

用于人工复审，或"独立上下文复审"（新会话只看 diff + 本文件 + `plan.md`）。

## 必查

- [ ] 音频回调线程是否引入了分配 / 锁 / IO / Python 调用
- [ ] 错误路径是否可能 panic（`unwrap` / `expect` / 越界索引）
- [ ] 注入是否按 UTF-16 码元发送
- [ ] 空文本是否会走到注入
- [ ] 新增路径是否在 `latency-budget.md` 登记额度，并附实测数字
- [ ] 日志是否泄漏了识别文本

## 判为 Important（阻断合并）

- P95 退化 >50ms 且无说明
- 某种合法输入会导致崩溃或静默失败（尤其提权窗口）
- 注入丢字 / 乱码 / 串窗
- 引入了对系统 Python 的隐式依赖

## 不算问题

- 命名风格、注释多少
- 覆盖率数字本身
- 测试文件数量

## 判定方式

1. 意图：这个变更是否解决了 `plan.md` 里写的问题？
2. 影响面：最坏情况会坏到什么程度？能否回滚？
3. 证据：有没有可复现的命令输出（测试、bench、注入回读）？
